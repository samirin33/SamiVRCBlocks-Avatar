# FixHandVector

## 概要

エディタ上でシーンに配置・親変更したとき、アバターの **手の先端・甲方向** に合わせてオブジェクトの回転を補正するコンポーネントです。
**TipVector** / **UpVector** で指定したローカル軸が、それぞれ指先方向・手の甲方向を向くように回転が決まります。

## 追加方法

- **Add Component** → **SamiVRCBlocks-Avatar** → **SB FixHandVector**
- 手の向きに合わせたいオブジェクト（小物・エフェクト原点など）にアタッチします。
- アバター階層内（Humanoid の手ボーンが解決できる位置）に置く必要があります。

## 使い方

### 基本手順

1. 補正したい GameObject に FixHandVector をアタッチ
2. **Hand Type** で Left / Right を選択
3. **Tip Vector** に「指先方向に合わせたいローカル軸」を指定（既定: Forward）
4. **Up Vector** に「手の甲方向に合わせたいローカル軸」を指定（既定: Up）
5. 配置・親変更・Inspector 変更時に自動で回転が再適用されます
6. 手動でやり直す場合は **手の向きに合わせて回転を再適用** ボタンを押す

### オプション・設定

| 項目 | 説明 |
|------|------|
| Hand Type | 補正に使う手（半身） |
| Tip Vector | 手の先端方向に合わせるローカル軸 |
| Up Vector | 手の甲方向に合わせるローカル軸 |

## 注意事項

- アバターの Humanoid マッピングから手の向きを推定します。マッピングが不正だと意図しない向きになります。
