# RemapPosition

## 概要

ソースの位置（基準からの相対）に **任意の倍率** をかけた位置へ、ターゲット（自身または指定オブジェクト）を VRC Position Constraint で動かすコンポーネントです。
**基準が未指定の場合はワールド原点 (0, 0, 0) を基準にします。**
ビルド時に Constraint の構造を自動生成します。倍率・Constraint の有効/無効・ウェイト・軸はアニメーションで操作でき、ビルド時に生成先のパスへ書き換えます。
エディタ上（非再生時）でも、ビルド後と同じ計算でターゲットの位置へ反映できます。

## 追加方法

- **Add Component** → **SamiVRCBlocks-Avatar** → **SB RemapPosition**
- 動かしたいオブジェクト（または近くのギミック用オブジェクト）にアタッチします。

## 使い方

### 基本手順

1. RemapPosition をアタッチ（このときターゲットの現在のローカル位置が「ウェイト 0 の位置」に記録されます）
2. **ターゲット** は追加時に自身が入る。別オブジェクトを動かす場合だけ差し替える（未指定なら自身）
3. **ソース** に位置の元になるオブジェクトを指定
4. 必要なら **基準** を指定。**未指定ならワールド原点 (0, 0, 0) が基準**
5. **倍率** を設定。「エディタで反映」がオンなら、シーン上のターゲットがすぐに動きます

### オプション・設定

| 項目 | 説明 | アニメーション |
|------|------|----------------|
| ターゲット | 位置を動かすオブジェクト。アバタールート自身は指定不可 | - |
| ソース | 位置の元になるオブジェクト | - |
| 基準 | ソースの位置をこのオブジェクトからの相対で測る。**未指定ならワールド原点 (0, 0, 0)** | - |
| 倍率 | 相対位置にかける倍率。負の値で反転。絶対値 0.001 未満は 0.001 として扱う | 可 |
| Constraint 有効 | オフで生成した Constraint をすべて止める | 可 |
| ウェイト | ターゲットの Position Constraint のウェイト。0 で「ウェイト 0 の位置」、1 でリマップ後の位置 | 可 |
| ウェイト 0 の位置 | ウェイト 0 のときのターゲットのローカル位置。追加時・ターゲット変更時に自動で記録 | - |
| 軸 (X/Y/Z) | リマップする軸（ターゲットの親のローカル軸） | 可 |
| エディタで反映 | オンのとき、エディタ非再生時にもターゲットの位置へ反映する | - |

**計算式**（ウェイト 1、全軸有効のとき）

`ターゲットのワールド位置 = ターゲットの親の位置 + (ソースの位置 - 基準の位置) × 倍率`

基準が未指定のときは `基準の位置 = (0, 0, 0)`（ワールド原点）です。
VRChat 上ではワールドの原点になるため、例えば倍率 0.01 で「ワールド内の位置を 1/100 に縮めたミニマップ」のような使い方ができます。

### アニメーション

このコンポーネントの `倍率` / `Constraint 有効` / `ウェイト` / `軸` を Animation ウィンドウで録画したクリップは、ビルド時に次のように書き換えます。

| コンポーネントのプロパティ | 書き換え先 |
|----------------------------|------------|
| `ratio` | `Remap_(ターゲット名)` の `m_LocalScale.x/y/z`（値は 1/倍率 に変換） |
| `constraintActive` | 生成したすべての VRC Position Constraint の `IsActive` |
| `weight` | ターゲットの VRC Position Constraint の `GlobalWeight` |
| `positionX/Y/Z` | ターゲットの VRC Position Constraint の `AffectsPositionX/Y/Z` |

倍率は 1/倍率 に変換するため、キー間の補間（直線・Ease など）は倍率側で見た形を保つよう細かくキーを打ち直します。

## ビルド時の挙動

Transforming フェーズ（Modular Avatar の後）で、ターゲットの親の下に次の構造を生成します（`Runtime/Components/Prefab/RemapPosition.prefab` と同じ構造）。

```
ターゲットの親
├─ ターゲット            … VRC Position Constraint（ローカル解決、ソース = SourcePosition）
└─ RemapPosition
   └─ Remap_(ターゲット名) … スケール = 1/倍率
      └─ RemapRatio       … VRC Position Constraint（ソース = 基準。未指定なら World プレハブ = ワールド原点）
         └─ SourcePosition … VRC Position Constraint（ソース = ソース）
```

SourcePosition はソースのワールド位置へ追従しますが、親のスケールが 1/倍率 なので、ローカル位置は「基準からの相対位置 × 倍率」になります。
ターゲットの Position Constraint はローカル解決なので、このローカル位置がそのままターゲットのローカル位置になります。
基準が未指定のときは、[WorldFix](02-world-fix.md) と同じ World プレハブ（シーンに置かないアセット）を RemapRatio のソースにして、ワールド原点へ固定します。

同じフェーズで、このコンポーネント向けのアニメーションカーブを生成先へ書き換えます。
VRCFury 等が後から追加したアニメーションも拾うため、Optimizing フェーズ（Modular Avatar の前）でもう一度書き換えてからコンポーネントを削除します。

## 注意事項

- 「エディタで反映」はターゲットの Transform を直接書き換えます。コンポーネントを外しても位置は戻らないので、必要なら「ウェイト 0 の位置」を参考に戻してください。
- エディタでの反映はアニメーションを再生しません（インスペクタの値で計算します）。
- ソース・基準がターゲット自身またはその子の場合は、循環するためスキップします（エディタ反映もしません）。
- ターゲットに既に位置を動かす VRC Constraint（Position / Parent）がある場合は警告します。
- 軸はターゲットの親のローカル軸です。基準の回転は使いません。
